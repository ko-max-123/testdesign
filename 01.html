作成ルール

設定
一括作成時は各Excelが混ざらないよう、親フォルダの直下にExcelファイル名のフォルダを自動作成します。
ID / シナリオID の作り方
端末・環境フォルダ
初期値として iOS と And を入れています。 不要なものは削除でき、必要な端末名・環境名を自由に追加できます。
IDモードでは、期待値が入っている行を区切りとしてIDをまとめます。 例: ID 1～7 の期待値が空欄で、ID 8 に期待値がある場合は、 個別の「1」「2」…ではなく 1~8 という1つのフォルダを作成します。 その次に ID 9～12 が続き ID 12 に期待値があれば、9~12 を作成します。
